# 🔴🔵 구슬 홀짝 게임 (Marble Odd-Even Web Game)

브라우저에서 바로 즐길 수 있는 심리전 베팅 웹 게임입니다.

## 🎮 게임 특징
- **1,000칩 기본 지급**: 원하는 만큼 칩을 베팅하고 홀/짝을 맞춰보세요.
- **연승 배당 보너스**: 3연승부터 연승 보너스 배당이 붙어 대박을 노릴 수 있습니다.
- **Web Audio 사운드 & 애니메이션**: 주머니 흔들림, 구슬 굴림, 승리 시 컨페티 연출까지 지원됩니다.
- **파산 구호금**: 칩을 모두 잃어도 무료 구호금(500칩)을 받아 다시 도전할 수 있습니다.
- **전적 통계**: 총 승률, 최대 보유 칩, 최장 연승 기록을 실시간 추적합니다.

## 🚀 플레이 방법
`index.html` 파일을 열거나 배포된 웹 링크로 접속하여 바로 플레이할 수 있습니다.
